UI Pages Implemented

📊

Dashboard /

KPI cards (total alerts, critical count, active incidents, avg AI score), 14-day stacked area chart for severity trends, category donut chart, top-priority alerts table sorted by AI score.

🛡

Alerts /alerts

Sortable table with 20 realistic alerts. Filters: severity, category, status, full-text search — all URL-persisted. Columns sort on severity, status, AI score, timestamp. AI score progress bar per row.

🤖

Alert Detail /alerts/:id

Full metadata panel, AI Threat Analysis (0–100 score meter + written rationale), MITRE ATT&CK section (colour-coded tactic pills + technique cards with IDs), IoC list (IP/domain/hash/URL/email), in-place status update via API.

🚨

Incidents /incidents & /incidents/:id

Incident card list. Detail view shows chronological investigative timeline, linked alerts with AI scores, metadata (assignee, created date, alert count).

🔗

MITRE ATT&CK Matrix /mitre

Interactive heatmap — tactic columns × technique rows, colour-coded by alert hit count (not seen → 1 → 2 → 3–4 → 5+). Hover tooltip with detail. Click technique → navigate to filtered alerts view. Per-tactic breakdown grid below the heatmap.

📈

Analytics /analytics

Severity trend + category donut, alerts by detection source horizontal bar chart, AI score distribution histogram (4 priority buckets), category × severity cross-tab table with per-category average AI scores.

Seed Data

20 high-fidelity alerts and 3 incidents — all with relative timestamps so the dashboard always shows "recent" activity.

Alerts include: Emotet malware, spear-phishing, SSH brute force, PowerShell obfuscation, DNS tunnelling exfiltration, ransomware file encryption, Pass-the-Hash lateral movement, CVE exploit privilege escalation, DDoS, OAuth abuse, credential stuffing, insider mass download, cron persistence, cryptomining, Kerberoasting, supply chain npm compromise, SQL injection probing, S3 bucket misconfiguration, and more.

Coverage: Every alert has AI score (0–100), plain-language AI rationale, MITRE tactic and technique tags (30+ unique techniques across 14 tactics), indicators of compromise (IPs, domains, file hashes, emails, URLs), and source system attribution.

Vite proxies /api/* to localhost:3001 automatically — no CORS configuration needed in development.
